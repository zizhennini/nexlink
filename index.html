Features

一块板，顶替你桌上一堆工具

探针、串口助手、逻辑分析仪、下载器、显示屏——NexLink 全给你收进 WiFi 里。

CMSIS-DAP 无线探针

DAPLink 内核原生支持，USB 插上即被 Keil / pyOCD / OpenOCD 识别为 CMSIS-DAP v2.1 探针；SWD 命令经 WiFi 转发，隔着房间也能下断点。

SWD · JTAG · SWO/ITM

无线串口桥

目标板 UART 经 WiFi 桥到浏览器或 TCP 3333，9600 ~ 921600 波特率动态切换，支持 HEX、时间戳、RX/TX 双色显示。

UART1 · TCP 3333 · 921600

协议分析仪

PWM 频率/占空比实时测量与输出；SPI 默认从机抓包、可切主机读写；I2C 嗅探读写事务，事务日志可导出 CSV。

PWM · SPI · I2C

OTA 双分区升级

浏览器选个 bin 就无线刷固件，ota_0 / ota_1 双槽互为备份，新固件启动异常自动回滚，再也不怕中途断电变砖。

ota_0 / ota_1 · 自动回滚

板载 SSD1306 OLED 六屏直翻菜单加 NexLink 开机动画，脱机也能操作；同一套状态在 Web 控制台远程预览、远程按键。

Pinout

16 Pin 排针，一根 USB-C 供电

整板 3.3V 直连 ESP32-S3，调试线、串口线、总线探针全部从这一排针引出。

排针信号ESP32-S3用途
5V / 3V3 / GND×2—USB-C 5V 直出、LDO 3.3V、共地
TXD0 / RXD0IO43 / IO44本板控制台日志（115200）
TXD1 / RXD1IO47 / IO21到目标板的串口桥（TCP 3333 / USB-TTL）
SCL / SDAIO10 / IO11I2C0，与 OLED 共用，可嗅探外部 I2C

SWCLK / SWDIOIO13 / IO14CMSIS-DAP 探针（dap 模式）
TDI / TDO / nTRSTIO48 / IO38 / IO39JTAG 调试（探针独占）

注意：排针全部 3.3V、无电平转换。接 3.3V 目标安全；接 5V 逻辑目标必须自行加电平转换。

1无线串口调试

TXD1→目标RX、RXD1←目标TX、GND，浏览器一连即得无线串口助手。

2SWD 调试 / 下载

SWCLK、SWDIO、NRST、GND，USB 角色切到 dap，Keil / pyOCD 直接认。

3USB-TTL 无线烧录

TXD1/RXD1 交叉 + NRST + 任一拓展 IO 接 BOOT，/api/dut/reset?boot=1 全程无线进下载模式。

4总线抓包

I2C 用 SCL/SDA；SPI 用拓展 IO 排 SCK/MOSI/MISO/CS；PWM 任意拓展 IO，Web「总线」页直接看。

Get Started

三分钟把固件跑起来

第一次用 USB 串口烧录，之后所有升级都走 OTA，无线完成。

方式一 · USB 串口首次烧录

到 Release v1.0.0 下载 nexlink.bin，USB 角色保持 OFF（原生 USB-Serial-JTAG，COM 口直连）：

# esptool 直接写入 app 分区（地址以分区表为准）
python -m esptool --chip esp32s3 -p COM11 -b 460800 \
  --before default_reset --after hard_reset \
  write_flash 0x10000 nexlink.bin
方式二 · OTA 无线升级（推荐）

板子连上 WiFi 后，浏览器打开 http://设备IP/，在「系统 → OTA」选 bin 刷入；或直接命令行：

# 限速 40K，避免小内存 HTTP 缓冲被打爆
curl -X POST -H "Expect:" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @nexlink.bin \
  --limit-rate 40K \
  http://192.168.4.1/api/ota

AP 模式默认：SSID NexLink-xxxx，密码 12345678，设备地址 192.168.4.1。
